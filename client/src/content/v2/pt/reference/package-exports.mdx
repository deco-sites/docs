## Scripts

| Subpath | O que faz |
|---|---|
| `@decocms/start/scripts/generate-blocks` | `.deco/blocks/*.json` → `blocks.gen.json` |
| `@decocms/start/scripts/generate-schema` | TS de section → `meta.gen.json` (JSON Schema) |
| `@decocms/start/scripts/generate-invoke` | registry de loader/action → `invoke.gen.ts` tipado |
| `@decocms/start/scripts/migrate` | Migração Fresh → TanStack |
| `@decocms/start/scripts/migrate-post-cleanup` | Limpeza pós-migração de boilerplate sobrando |
| `@decocms/start/scripts/tailwind-lint` | Lint/fix Tailwind v3 → v4 |

Invoque via `npx tsx node_modules/@decocms/start/scripts/<name>.ts` ou como binário:

```bash
npx -p @decocms/start deco-migrate
npx -p @decocms/start deco-post-cleanup
npx -p @decocms/start deco-htmx-analyze
```
