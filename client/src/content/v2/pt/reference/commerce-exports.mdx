A tabela completa de exports de `@decocms/apps` (versão `^1.11`). Gerada do mapa `exports` em [`package.json`](/Users/fernandofrizzatti/development/workspace/decocms/apps-start/package.json).

<Callout type="warning">
**Watch de drift.** O README de `@decocms/apps` referencia `@decocms/apps/vtex/invoke` — esse subpath **não** existe no `package.json`. Use rotas HTTP `/deco/invoke/...` (cuidadas pelo seu `invoke.gen.ts` gerado) e as factories `createUseCart` / `createUseUser` / `createUseWishlist` de `@decocms/apps/vtex/hooks` em vez disso.
</Callout>

O app Website provê utilities que toda loja usa (config Seo, carregamento de fonte, redirect-from-CSV). Não é "commerce" — é o cinto de utility genérico de site.
