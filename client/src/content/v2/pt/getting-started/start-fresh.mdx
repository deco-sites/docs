Esta página leva você do zero até uma loja v2 em produção. O caminho mais rápido hoje é **clonar uma loja de referência mínima** e customizar a partir dela — um `npm create deco` dedicado está no roadmap, mas ainda não saiu.

<Callout type="info">
**Pré-requisitos:** Node.js 20+, um package manager (`npm`, `pnpm` ou `bun`), uma conta Cloudflare e (opcionalmente) uma loja VTEX ou Shopify se você quer commerce.
</Callout>

## 1. Clone uma loja de referência

O ponto de partida mais limpo é **Le biscuit** — a mais "espinha dorsal" das três referências. Usa todos os defaults sem customização pesada.

```bash
git clone https://github.com/deco-sites/lebiscuit-tanstack minha-loja
cd minha-loja
rm -rf .git node_modules
git init
```

Se quiser uma base mais rica (analytics, Sentry, Firebase, fetch regional), use **Casa&Vídeo** como ponto de partida — mas conte com mais código para apagar.

## 2. Instale as dependências

```bash
npm install
```

As peer dependencies que precisam estar presentes (já fixadas no `package.json` da referência):

- `@decocms/start ^2.28`
- `@decocms/apps ^1.11`
- `@tanstack/react-start ^1.166`
- `react ^19`, `react-dom ^19`
- `vite ^6`
- `wrangler ^4`

## 3. Aponte para o seu próprio decofile

Cada site precisa do seu próprio `siteName` e do conteúdo em `.deco/blocks/`. O CMS guarda o conteúdo em dois lugares:

1. **`.deco/blocks/*.json`** — fonte da verdade, commitada. Edite via `admin.deco.cx`, sincronize para disco com o daemon.
2. **`src/server/cms/blocks.gen.json`** — bundle gerado que o framework carrega em runtime.

Atualize o identificador do site em [`src/setup.ts`](/Users/fernandofrizzatti/development/workspace/decocms/lebiscuit-tanstack/src/setup.ts) e em `cmsRouteConfig({ siteName: "sua-loja" })` dentro de `src/routes/$.tsx` e `src/routes/index.tsx`.

Em seguida regenere o bundle:

```bash
npm run generate:blocks
```

## 4. Configure commerce (opcional)

Se sua loja usa VTEX ou Shopify, configure o block correspondente no admin (ou direto em `.deco/blocks/`). VTEX precisa de `account` mais os secrets `appKey`/`appToken`; Shopify precisa de `storeName` mais um Storefront access token. Veja [Visão geral de commerce](/v2/pt/commerce/overview).

## 5. Rode o dev server

```bash
npm run dev
```

O Vite serve a loja em `http://localhost:5173` (ou qualquer `PORT` que você configure). A primeira requisição dispara o tunnel do daemon que mantém `admin.deco.cx` em sincronia com seu site local.

## 6. Gere tipos e rotas

Depois de editar sections, blocks ou rotas, regenere os arquivos auxiliares:

```bash
npm run generate:blocks   # blocks.gen.json
npm run generate:schema   # JSON Schema para o admin
npx tsr generate          # tipos do TanStack Router
```

O `package.json` das lojas de referência expõe esses comandos como scripts compostos; consulte [`lebiscuit-tanstack/package.json`](/Users/fernandofrizzatti/development/workspace/decocms/lebiscuit-tanstack/package.json) para o setup canônico.

## 7. Deploy no Cloudflare Workers

```bash
npx wrangler deploy
```

Você precisa de um `wrangler.jsonc` com:

```jsonc
{
  "name": "minha-loja",
  "main": "./src/worker-entry.ts",
  "compatibility_date": "2026-02-14",
  "compatibility_flags": ["nodejs_compat", "no_handle_cross_request_promise_resolution"]
}
```

Configure secrets via `wrangler secret put` ou pelo painel do Cloudflare. Veja [Deployment no Cloudflare Workers](/v2/pt/deployment/cloudflare-workers) para bindings de KV, observabilidade e checklists de produção.

## O que vem pronto

Clonar uma loja de referência já entrega:

- O pipeline de build Vite + Cloudflare + TanStack Start ([`vite.config.ts`](/Users/fernandofrizzatti/development/workspace/decocms/lebiscuit-tanstack/vite.config.ts)).
- O Worker entry com rotas do admin e cache de borda ([`src/worker-entry.ts`](/Users/fernandofrizzatti/development/workspace/decocms/lebiscuit-tanstack/src/worker-entry.ts)).
- O setup do site com glob de sections, blocks, matchers e init de plataforma ([`src/setup.ts`](/Users/fernandofrizzatti/development/workspace/decocms/lebiscuit-tanstack/src/setup.ts)).
- A rota catch-all + home via `cmsRouteConfig` / `cmsHomeRouteConfig`.
- Os arquivos gerados `blocks.gen.ts`, `sections.gen.ts`, `meta.gen.json`, `loaders.gen.ts`.

Você pode ir trocando peça por peça no seu ritmo.
