The **Module** column is the `--only` / `--skip` scoping key for [`parity run`](/v2/en/parity/run#focused-runs) (or run `parity list modules`). Results are aggregated (optionally via Claude) and ranked by severity; each issue includes screenshots, reproduction, and a suggested fix.

| Check | What it catches | Module |
| --- | --- | --- |
| HTTP status parity | Routes that 404 / 500 in cand but worked in prod | `seo` |
| Console errors | New hydration mismatches, failed fetches, JS exceptions | `console` |
| HTML structural diff | Section / element counts drifting beyond tolerance | `html` |
| Meta / SEO parity | `<title>`, meta description, canonical, `og:*`, twitter, JSON-LD | `seo` |
| Visual diff (LLM Vision) | Sections missing, wrong hero, broken shelf, layout shifts | `visual` |
| Purchase journey | Home → PLP → PDP → CEP → cart → checkout completes in both | `e2e` |
| PLP pagination | Next-page / load-more / infinite-scroll work; `?page=N` fallback | `seo` |
| Network summary | Request count / bytes / cache hit rate | `network` |
| Web Vitals | LCP, FCP, TTFB, INP, CLS — mobile + desktop | `vitals` |
| Image loading health | Missing alt, no srcset, broken `<img>` | `html` |
| Lazy section presence | Deco render/loader routes responding | `html` |
| Banner aspect ratio | Hero/banner images keep the same ratio (CLS/crop) | `visual` |
| SEO deep audit | robots.txt, sitemap, noindex regressions | `seo` |
| Cache coverage | Cache hit rate, opportunities to cache | `cache` |
| Search presence / autocomplete / results / no-results | Search reachable, suggestions, comparable counts, empty state | `e2e` |
| Cart interactions | Multi-item add / qty / persistence / coupon / remove | `e2e` |
| 404 parity | Invalid URL returns 404 (no catch-all 200) | `seo` |
| Cookie/CEP modal CLS | Modals don't shift layout > 0.1 | `visual` |
| PDP gallery + related | Gallery + "Related products" shelf render | `e2e` |
| PDP breadcrumbs | Breadcrumb (markup or JSON-LD) renders on PDP | `e2e` |
| PLP sorting | `?sort=`/`?orderBy=` actually reorders products | `e2e` |
| Footer links health | Institutional links aren't broken | `seo` |
| Login flow _(opt-in)_ | Valid creds log in; invalid ones show an error | `e2e` |
| Picture missing dims | `<picture>` without width/height (static CLS) | `html` |
| Cart reveal mode | prod/cand cart-reveal markup intent matches | `e2e` |
| SPA navigation | Client-side route change doesn't drop CMS sections vs F5 | `e2e` |
| Server-fn hover flood | Hovering cards doesn't flood `_serverFn`/preload requests | `e2e` |

## Running one check

```bash
parity check meta-seo-parity --prod https://old.com --cand https://new.dev
```
