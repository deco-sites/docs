The complete export table for `@decocms/apps` (version `^1.11`). Generated from [`package.json`](/Users/fernandofrizzatti/development/workspace/decocms/apps-start/package.json) `exports` map.

<Callout type="warning">
**Drift watch.** The `@decocms/apps` README references `@decocms/apps/vtex/invoke` — this subpath does **not** exist in `package.json`. Use `/deco/invoke/...` HTTP routes (handled by your generated `invoke.gen.ts`) and the `createUseCart` / `createUseUser` / `createUseWishlist` factories from `@decocms/apps/vtex/hooks` instead.
</Callout>

The Website app provides utilities every storefront uses (Seo config, font loading, redirect-from-CSV). It's not "commerce" — it's the generic site-level utility belt.
